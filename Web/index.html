Historia de las Tecnologías Web

Conoce la evolución de HTML, CSS, JavaScript, Node.js y TypeScript.

HTML CSS JavaScript Node.js TypeScript Comparación

HTML

HTML (HyperText Markup Language) nació en 1991 gracias a Tim Berners-Lee. Es el lenguaje encargado de definir la estructura de las páginas web.

Evolución

  • HTML 1.0 (1991) Primer lenguaje para documentos web.
  • HTML 2.0 (1995) Se convierte en un estándar.
  • HTML 3.2 (1997) Agrega tablas y mejoras visuales.
  • HTML 4.01 (1999) Separa mejor contenido y diseño.
  • XHTML (2000) Basado en XML.
  • HTML5 (2014) Multimedia, formularios avanzados y nuevas etiquetas semánticas.

CSS

CSS (Cascading Style Sheets) fue creado por Håkon Wium Lie en 1996.

¿Qué problema resolvió?

Antes de CSS todo el diseño debía hacerse dentro del HTML utilizando etiquetas como <font>, lo que hacía el código muy difícil de mantener.

CSS permitió separar el contenido del diseño, facilitando la creación de páginas más organizadas, modernas y fáciles de modificar.

JavaScript

Fue creado por Brendan Eich en 1995 en apenas 10 días mientras trabajaba para Netscape.

Impacto en la web

  • Páginas interactivas.
  • Validación de formularios.
  • Animaciones.
  • Aplicaciones web modernas.
  • Desarrollo Front-End.

Node.js

En 2009 Ryan Dahl creó Node.js para ejecutar JavaScript fuera del navegador.

Gracias al motor V8 de Google Chrome fue posible desarrollar servidores, APIs, aplicaciones en tiempo real y herramientas de desarrollo utilizando JavaScript.

TypeScript

Microsoft presentó TypeScript en 2012.

¿Por qué surgió?

Los proyectos grandes escritos únicamente con JavaScript eran difíciles de mantener y detectar errores.

¿Qué aporta?

  • Tipado estático.
  • Autocompletado.
  • Mayor seguridad.
  • Código más mantenible.
  • Mejor experiencia para proyectos grandes.

JavaScript vs TypeScript
